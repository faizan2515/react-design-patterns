# Bundled fonts

Both are licensed under the SIL Open Font License 1.1, which permits bundling and
redistribution with this project. Only the `latin` subset is included, as variable
`woff2` covering the full weight axis.

| File | Family | Source | License |
| --- | --- | --- | --- |
| `martian-mono-latin.woff2` | Martian Mono, by Evil Martian | https://github.com/evilmartians/martian-mono | SIL OFL 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono, by JetBrains | https://github.com/JetBrains/JetBrainsMono | SIL OFL 1.1 |

Martian Mono is the display face: headings, the wordmark, and instrument labels.
JetBrains Mono is the code face: source panels, tabs and readouts.
Body prose stays on the system sans stack — the site's voice lives in the monospace.
